# THE PLANET OF THAIANE

A desktop game built with SFML C++

## Story 

in a world invaded by robots.
Two close friends are separated after one of them is kidnapped ,
and the player takes on the mission to rescue them.

## Features

• Player movement system (gravity, jumping, collision)
• Shooting mechanics with cooldowns
• Enemy AI (basic decision-making + delayed reactions)
• Bullet system using vectors and structs
• Health & damage systems with timers (cooldowns)
• Multi-level navigation system (page-based world)
• Sprite animation system ( run, jump, attack)
• Basic vehicle system (drivable car with interactions)

## Technologies

- C++
- SFML
